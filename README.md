# Chinese Codex Pets

A small collection of China-inspired Codex custom pets for Petdex and the Codex app.

## Pets

- `giant-panda` - Giant Panda, a gentle black-and-white panda companion.
- `red-panda` - Red Panda, a curious red panda with a ringed tail.
- `xixi` - Xixi, a Chinese rural dog with brown-and-white markings.

## Package Format

Each pet lives under `pets/<pet-id>/` and contains:

- `pet.json`
- `spritesheet.webp`

The spritesheet follows the Codex pet atlas format: `1536x1872`, 8 columns by 9 rows, with 192x208 cells.
